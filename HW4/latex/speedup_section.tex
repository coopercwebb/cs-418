\textbf{Methodology:}

The performance benchmarking methodology for \code{par\_len} closely follows the approach used in HW1 for parallel prime finding. The benchmark implementation can be found in \code{hw4\_test.erl} (lines 262-365). The implementation uses the \code{time\_it:t/1} function from the course library to measure execution times. Key similarities to HW1 methodology:
\begin{itemize}
    \item \textbf{Baseline measurement}: Sequential version (\code{hw4\_lib:sim\_len\_ms}) establishes baseline performance
    \item \textbf{Multiple worker configurations}: Tests with varying numbers of workers to identify optimal parallelism
    \item \textbf{Large workload}: Uses N\_trials = 200, N\_warmup = 10000, N\_run = 5000
    \item \textbf{Timing methodology}: \code{time\_it:t/1} runs the timed function repeatedly until at least 1 second elapsed
    \item \textbf{Speedup calculation}: Speedup = $\frac{\text{Sequential Time}}{\text{Parallel Time}}$
\end{itemize}
